# Accordion

A FAQ-style accordion using native `<details>` / `<summary>`. No JavaScript.

### Classes
| Class | Purpose |
| --- | --- |
| `.ui-accordion` | Wrapper |
| `.ui-accordion__panel` | Content area inside each `<details>` |

### Options
- **Open by default:** add the `open` attribute to a `<details>`.
- **Only one open at a time:** give every `<details>` the same `name` attribute (`<details name="faq">`). Supported in current Chrome, Edge, Safari and Firefox.

### Accessibility
- Keyboard: `Tab` to a summary, `Enter` / `Space` toggles. Announced as a disclosure widget by screen readers.
- The + / − icon is generated by CSS and is not the only state indicator: the open item also gets an accent bar and colored title.
- 3px focus ring; high-contrast (`forced-colors`) fallback.

## Markup

```html
<div class="ui-accordion">
  <details>
    <summary>Who can join?</summary>
    <div class="ui-accordion__panel">
      <p>Anyone with a connection to the organization is welcome to apply.</p>
    </div>
  </details>
  <details>
    <summary>What does membership include?</summary>
    <div class="ui-accordion__panel">
      <p>Members get access to events, reservations and shared spaces. <a href="#details">See full details</a>.</p>
    </div>
  </details>
  <details>
    <summary>How do I contact you?</summary>
    <div class="ui-accordion__panel">
      <p>Email <a href="mailto:info@example.com">info@example.com</a> or visit us in person.</p>
    </div>
  </details>
</div>
```

## Usage

```html
<link rel="stylesheet" href="css/components.css">
```

Or include only `css/tokens.css` and `css/accordion.css`. Open `example.html` in a browser to see it on its own.
